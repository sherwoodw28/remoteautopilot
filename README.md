# SHIP REMOTE AUTOPILOT

Ship Remote Autopilot gives the player the ability to remotely "summon" their ship to a selected location.
*This is experimental technology from Outer Wilds Ventures and, as such, remains fairly rudimentary. Use at your own risk.*

## How do I use the Remote Autopilot?

1. Select a destination using the controls listed below.
2. Activate the Remote Autopilot (shocker).
3. If the ship is currently landed, it will fire its upward thrusters for 10 seconds to clear the surface.
4. The ship will then engage its normal autopilot and travel towards the selected destination.
5. Once *(and if)* it reaches the destination, the ship will enter an **automatic descent** and attempt to land.

The Remote Autopilot can be aborted at any point using the Abort control.

## Important Notes

- **THIS TECHNOLOGY IS INTENDED AS A "LAST RESORT" RESCUE SYSTEM IF YOU BECOME STRANDED.**
*Outer Wilds Ventures does not recommend using the Remote Autopilot as your normal mode of transportation.*

- **AUTOMATIC LANDING TECHNOLOGY IS EXPERIMENTAL.**
*The ship will attempt to control its descent and land safely, but difficult terrain or unusual circumstances may result in a non-optimal landing.*

# Controls

By default, Ship Remote Autopilot uses the Number Pad.

In the mod settings, **Alternate Keys Mode** can be enabled for keyboards without a Number Pad.

> **Please note:** Alternate Keys Mode may conflict with controls used by other mods.

## Controller Controls

Hold the **Left Shoulder Button** while using the D-Pad.

| Action | Control |
| --- | --- |
| Previous Destination | Left Shoulder + D-Pad Left |
| Next Destination | Left Shoulder + D-Pad Right |
| Activate Autopilot | Left Shoulder + D-Pad Up |
| Abort Autopilot | Left Shoulder + D-Pad Down |

Selecting a destination will display the currently locked destination on the HUD.
